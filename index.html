01 / Front-end · Brand

BurgerBox

A fictional fast-food brand, built like a real one.

A full ordering experience for a made-up burger chain: the menu is data-driven, every item opens a customiser for size, toppings and sauces, and the cart and checkout work from end to end. All of the food art is hand-drawn SVG, so the site ships without a single photo.

  • Data-driven menu, item customiser, cart and demo checkout
  • Hand-drawn SVG illustration instead of image files
  • Layout holds up from phone to widescreen
  • HTML
  • CSS
  • JavaScript
  • SVG

02 / Next.js · Tailwind

The Cut Barbershop

A premium barbershop site that sells the booking.

A services-and-gallery page for a traditional barber shop: a priced service menu with durations, grooming products, a photo gallery, client testimonials and a location and opening-hours panel. Built with Next.js and Tailwind CSS, so every block is its own component.

  • Priced service menu with durations and a booking call to action
  • Gallery, product and testimonial sections in one flow
  • Component-based Next.js build deployed on Vercel
  • Next.js
  • React
  • Tailwind CSS
  • Vercel

03 / Web app · Product

FlowUle

“Your schedule, tasks, reminders and social life, all in one place.”

The most product-like thing I’ve built. FlowUle is a student organiser with real accounts, passwords and per-user data behind the sign-in: you build your own weekly schedule, keep tasks and reminders, and stay in touch with the people you study with. It’s built for a phone screen first, then scaled up.

  • Sign-up and sign-in with private, per-user data
  • Weekly schedule, tasks and reminders in one view
  • Runs as a full Next.js app on Vercel
  • Next.js
  • React
  • Accounts
  • Vercel

About
